### КТ №42. Финализируемый объект и IDisposable (Вариант 2 - Лог-файл)

**Демонстрация:**
- Сценарий `using`: файл открывается и сразу закрывается (детерминированное освобождение).
- Сценарий без `Dispose`: файл остается открытым до тех пор, пока сборщик мусора не запустит финализатор.

**Вывод консоли:**
4. LogFile: корректный и некорректный сценарии
[LogFile 1] файл открыт: test_log.txt
[LogFile 1] файл закрыт
После корректного using-блока
[LogFile 2] файл открыт: test_log.txt
Метод с забытым Dispose завершён
[LogFile 2] финализатор! – файл не был закрыт явно
После сборки: сработал финализатор

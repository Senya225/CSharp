 КТ №40. GC в .NET 10: поколения, регионы памяти (DATAS)

Вариант 2. Измерение давления

Описание работы
В ходе работы были выполнены сценарии, создающие разное давление на управляемую кучу:
1. Много мелких объектов (`byte[100]`).
2. Несколько крупных объектов (`byte[100_000]`), попадающих в LOH.
3. Удержание долгоживущих объектов (`byte[512]` в статическом списке).
4. Принудительная блокирующая сборка Gen2 (`GC.Collect(2)`).
